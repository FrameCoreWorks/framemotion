# Motion workshop

The workshop is FrameMotion's working knowledge for planning and judging a film: tested values and techniques written as defaults, plus the conditions under which another tool is the better choice. It came from the FrameCore Works Motion project (lessons from produced reels, 2026-11) and was rewritten here in general terms; brand rules from that project are not part of it.

## How to use it

1. Read the [decision table](decisions.md) before choosing transitions, cuts, glow, particles, shake, overshoot, sound or the engine. It is the router: a default, and when something else is allowed.
2. Plan motion with [motion](motion.md), choose techniques from [techniques](techniques.md), set the look with [look](look.md), set type with [typography](typography.md), and use [editing](editing.md) for voice-over, footage, music cut to length, captions or 15/30/60-second versions. Realistic objects and materials: [3D and Blender](3d.md).
3. Every exception to a default is written in the film's plan with its reason (what on screen causes it). The user's brief and brand always win over the workshop.

## The open-workshop rule

- Lessons from revisions are defaults and lists of conditions under which something did not work, not lifelong bans. A tool from another source may be used when the condition is different and there is a reason on screen.
- Propose directions the user has not seen yet (technique, style, editing, sound) instead of repeating a proven set, and justify the choice in the plan.
- Hard limits remain only where the user or the brand names them as rules (for example ethics, no ambiguous poses of people or characters).
- Research covers the whole field (titles, advertising, music videos, broadcast, film, games), not only short vertical reels; the conversion to the delivery format happens when building.
- Only tested knowledge enters these files. Untested tools wait in the [test queue](test-queue.md); after a test they move into the right file or are dropped with the reason.

Before an exception, ask: does it have a cause on screen, does it strengthen the emotion or the story, was it used in the previous film (variety), does it cover text?
