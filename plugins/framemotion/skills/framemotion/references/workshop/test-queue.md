# Test queue

Tools and techniques that are not yet tested. They are not defaults and never appear in a plan as proven. After a test, a working item moves into the right workshop file; a failing one is removed with the reason.

- Flubber (MIT): morphing SVG paths with different point counts.
- troika-three-text (MIT): sharp MSDF text in three.js with lighting.
- Forced alignment (WhisperX or similar): the time of each voice-over word as JSON, captions from data.
- Supersampling in three.js: sub-frame accumulation with sub-pixel camera jitter (better anti-aliasing than `tmix`?).
- A halftone or risograph shader (Bayer 8×8) as a film finish.
- three.js WebGPU and TSL class names (post-processing, `HDRLoader` instead of `RGBELoader`): check current documentation before using WebGPU.
