Seven files are changed, each marked by a "FrameMotion:" comment and recorded with the upstream and current SHA-256 in [source-manifest.json](source-manifest.json): `util.py` downloads no model unless `REA_VIDEO_DOWNLOADS=1` is set after the user agrees, `cli.py` runs the stem split only with `--stems`, `cli.py` and `memory.py` drop the capsule-cinema commands and the eval command, and `audio.py`, `pipeline.py`, `playbook.py` and `sound_source.py` no longer name capsule-cinema tools in their advice. `evaluate.py` is left out. Not bundled: the docs (with the TikTok and Douyin clips in docs/cases), the READMEs, the agent skill, the capsule-cinema integrations, the evaluation set and scripts, and the `[asr]` extra. No model is bundled; a model is downloaded only with that yes and checked against its pinned hash. The dependencies are pinned in `rea-video-requirements.txt` next to the package.
