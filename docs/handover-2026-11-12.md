# Handover 2026-11-12: FrameMotion 0.1.0

## What happened

The owner said "startujemy" on 2026-11-12 for moving the whole Motion Graphics module out of FrameCore Works Creative Studio into its own plugin. This repository was created the same day (public, `main` only) and holds FrameMotion 0.1.0.

Decisions by the owner (2026-11-12): the whole module moves; Studio keeps only a pointer and a companion entry; FrameMotion works standalone and as Studio's companion, like Toolbox and Open Assets; no light version for ChatGPT Work; Apache-2.0; one skill; the old paths in Studio are deleted physically in the Studio release that follows (owner card answer, option A), with the list in Studio's changelog.
